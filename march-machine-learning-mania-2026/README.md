# Project Overview
This is my **March Machine Learning Mania 2026** competition code. The competition is officialy organised by the **Kaggle** platform. The goal is to forecast the outcomes of both the men's and women's 2026 collegiate basketball tournament submitting predictions for every possible tournament matchup.
